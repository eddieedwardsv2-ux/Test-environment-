# Grill me (get knowledge out of the user's head)

A quick brain dump is never enough; this asks until nothing is missing.

## Steps
1. **Open the capture file first:** `brainstorms/YYYY-MM-DD-<topic>.md`
   (create `brainstorms/` if missing; continue an existing file on the same
   topic). Sections: Summary · Key decisions · Q&A log · Open flags.
2. **Ask one question at a time.** Settle the decisions others depend on
   first, and give your recommended answer with each question. If the files
   already answer it, look instead of asking.
3. **Checkpoint after every answer:** add the Q and A to the log and update
   Summary and Key decisions. Nothing lives only in chat.
4. **Flag what the user can't answer** (someone else knows, or it needs
   checking) under Open flags. Don't guess.
5. **Stop** when you both understand it the same way, or the user says stop.
6. **Follow through:** name the files or skills this changes (e.g.
   `context/about-me.md`) and ask before updating them. Log big decisions in
   `decisions.md` with the date.

## Check
Read the Summary back and ask: "Is anything wrong or missing?" Keep private
details out of the files if the repo is public.
