# Research (knowledge base, level 2)

Add this only when you have about 30+ notes and keep forgetting what's in them.

- **Raw evidence:** `research/<source>/` holds the original material
  (transcripts, posts, articles). Raw files are never edited.
- **Derived brain:** `research/<source>/brain/` holds what was learned, built
  from the raw files: `index.md` (what's here now, the entry point),
  `log.md` (what was added when), `concepts.md` and `rules.md` (every claim
  with an exact quote and its source; anything unsourced is labelled
  "inference").
- **Ingest** updates every page a new source touches, then the index and log.
- Only store what will still be useful in a year; you decide what goes in.
