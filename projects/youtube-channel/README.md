## Nate media-production proof gate — journey Short (2026-10-10)

Source method: Nate Herk, **“Opus 5.5 Just Changed Video Editing Forever (free skills)”** (`7jHXoPGnA4c`). Full timestamped transcript is saved in `research/nate-herk/`; segmented derived notes are `research/nate-herk/opus-5-5-video-editing-workflow--7jHXoPGnA4c-notes.md`.

Use this as the default production order for the first real Short:
1. **Transcribe / timing source** — final voice-over or script becomes the time-aligned source.
2. **Cut** — remove mistakes, dead air and redundant phrasing before expensive motion work.
3. **Plan beats** — map story beats to exact moments and state what good looks like.
4. **Skill / assembly** — reuse the smallest suitable capability; capture repeated visual preferences in a short skill and refine it from concrete output feedback.
5. **Verification loop** — render, inspect video/audio/framing/branding, record defects, rerender, then watch the final output end to end after the last change.
