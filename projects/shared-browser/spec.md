# Charlie's shared iPhone browser

Charlie authorised creation and hosting on 9 October 2026. Scope: an iPhone 16
Plus home-screen app, live touch and keyboard controls, saved browser profile,
reconnect, and My turn / AI's turn handoff. Reuse installed Chromium and noVNC.
The proposed Selkies image filled the disk; it was removed before use.

First hosting route: free temporary HTTPS tunnel from this running workspace.
This is not guaranteed always-on hosting; a permanent VM needs an account and
approval of any price. Phone pairing requires local approval of a displayed
code; the code alone cannot log in. Approved device cookies last up to 30 days.
Profiles, tokens and device records stay outside this public repository.
No browser credentials or screenshots enter the PWA cache. AI cannot access
page contents or act while the phone owns control. Codex uses the private API
against the exact same live Chromium tab; no automatic model spending.

Done when: unauthorised HTTP/WebSocket access fails; device pairing succeeds;
sessions survive gateway restart and simulated 16 minutes; human takeover
revokes AI control; the real browser works via touch, keyboard and private API;
430x932 portrait and landscape layouts fit; external HTTPS works.
Actual iPhone hardware/network, long-term uptime, third-party login expiry and
Higgsfield/Katana access are not covered by automated workspace checks.
